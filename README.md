# Garage Project
 
A comprehensive vehicle management system for tracking maintenance, costs, and sharing your garage with friends.
 
## Features
 
### 🚗 Vehicle Management
- Track multiple vehicle types (Cars, Trucks, Motorcycles, Boats, RVs)
- Vehicle status tracking (Active, Sold, Crashed, Traded)
- Purchase and sale information with profit/loss calculations
- Image uploads for each vehicle
 
### 🔧 Maintenance Tracking
- Log maintenance records with dates, costs, and descriptions
- Upload receipts for maintenance records
- Track maintenance by category (Oil, Tires, Brakes, etc.)
- View maintenance history for each vehicle
 
### 🛠️ Aftermarket Parts
- Track aftermarket modifications and parts
- Record part costs and installation dates
- Upload receipts for parts purchases
- Calculate total investment in modifications
 
### 👥 Social Features
- Friend system with unique friend codes
- Share your garage with friends
- Privacy controls for each vehicle and data field
- View friends' garages and their vehicles
 
### 🔒 Privacy Controls
- Granular privacy settings for each vehicle
- Control visibility of VIN, mileage, and purchase info
- Choose which vehicles to share with friends
- Real-time privacy toggle updates
 
### 📱 Mobile Friendly
- Responsive design for all screen sizes
- Touch-optimized interface
- Native camera and photo library integration
- Drag-and-drop file uploads
 
## Tech Stack
 
- **Backend**: Flask (Python)
- **Database**: SQLite with migration system
- **Frontend**: HTML5, Jinja2 templating
- **Styling**: Tailwind CSS
- **Image Processing**: PIL (Pillow)
- **Security**: Werkzeug password hashing
